Dynamic Charts

Welcome to Dynamic Charts

Turn a few numbers into a fully editable chart — built from real layers on the canvas, not a pasted image.

Before you start: this plugin renders text using the Noe Display and Moderat fonts. Make sure they're installed in your Figma account — without them, chart creation will fail.
  1. Pick a chart type Vertical, horizontal, line, pie, and more — see the icons above.
  2. Choose a look Positive (light), Negative (dark), or pick your own color.
  3. Add your data Fill in a label and a value for each row. Some chart types have a second value column too — just fill that in to compare.
  4. Hit Create Your chart lands on the canvas as fully editable native layers.
  5. Edit anytime Select an existing chart on the canvas and its data loads back into this panel. Change the values and hit Update to refresh it.
